# SwiftPOS Retail Point-of-Sale

**Status:** Active Development (MVP Phase)  
**Last Update:** March 23, 2026 (Milestone 0.5 Complete)

## Quick Start

```bash
# Start PostgreSQL container
docker run --name swiftpos-pg \
  -e POSTGRES_USER=swiftpos \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=swiftpos \
  -p 127.0.0.1:5432:5432/tcp \
  -d postgres:16-alpine

# Seed database (from project root)
npx tsx scripts/seed-pg.ts

# Start development server
USE_POSTGRES=true npm run dev
```
