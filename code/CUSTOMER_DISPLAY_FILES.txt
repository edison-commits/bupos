QUICK START
═══════════════════════════════════════════════════════════════

1. URL to display page:
   http://localhost:3000/register/customer-display

2. In POS register, add BroadcastChannel code:
   const channel = new BroadcastChannel('basicuniformpos_customer_display');
   
   channel.postMessage({
     type: 'cart_update',
     cart: currentCart,
     appliedPromo: promoCode,
     exchangeCredit: exchangeCredit
   });

3. On transaction complete:
   channel.postMessage({ type: 'cart_clear' });

4. Open display on customer-facing monitor
5. Test by adding items to cart
